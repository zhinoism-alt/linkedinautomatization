# Portafolio

Casos documentados para enseñar en entrevistas. Cada caso se estructura así:

1. **Contexto de negocio** (planta manufacturera, problema)
2. **Requerimiento** (como lo diría el usuario)
3. **Solución** (configuración, transacciones, integración FI/CO)
4. **Pruebas** (escenarios y resultados esperados vs. reales)
5. **Evidencia** (capturas y asientos)
