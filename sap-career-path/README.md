# SAP Career Path: de SAP ECC FI a consultor S/4HANA (meta: 50k+ MXN/mes en 2027)

Repositorio para documentar mi learning path, mis laboratorios hands-on y mi portafolio de configuración SAP.

## Perfil de partida

| Activo | Cómo lo aprovecho |
|---|---|
| Experiencia SAP ECC (Finanzas) | Base FI: GL, AP, AR, AA, cierres. Es el punto de integración de MM (OBYC, MIRO) |
| Experiencia en manufactura | Conozco procesos reales de compras, inventario, costeo y producción |
| Ingeniería en Software | Diferenciador técnico-funcional: ABAP, CDS, OData, BTP, integraciones |

## Posicionamiento objetivo

> **SAP S/4HANA Finance & Procurement Consultant (FI + MM/P2P + Product Costing) | ECC → S/4HANA migration | Manufacturing**

Por qué este perfil (según lo que piden las vacantes reales, ver [market research](01-market-research.md)):

- Las vacantes de **MM** piden siempre **integración con FI y CO** (valuación, verificación de facturas, cierre de mes logístico). Viniendo de FI, eso ya lo tengo.
- Las vacantes mejor pagadas que encontré (**75k–90k MXN**) son de **CO-PA / Material Ledger / Product Costing**, justo lo que se usa en manufactura.
- ECC termina su mantenimiento estándar a finales de **2027**, así que hay mucha demanda de gente que conozca ECC y S/4.
